# Aayush Tech — "Cyber Matrix" Edition

> The cyberpunk/holographic edition of the Aayush Tech website — neon effects,
> matrix rain, 3D visuals, and a full suite of built-in cyber tools.

## Features

- 🌐 **Cyberpunk / holographic UI** — animated backgrounds, matrix rain, floating cubes
- 🚀 **Animated loading screen**
- 🛠️ **7 built-in cyber tools** — calculator, weather widget, unit converter,
  password generator, color picker, calendar, text tools
- 🔔 **Notification system** with demo buttons
- 📱 **PWA + offline support** via service worker
- 📬 **Contact form** and portfolio section
- ♿ **Skip-to-content** accessibility link
- 🔄 **Version checker** (`api/check-updates.js`)
- 📰 Blog, petition, members, services pages

## Getting Started

```bash
cd Official-Aayush-tech07
python3 -m http.server 8000
# open http://localhost:8000
```

Or open `index.html` directly.

## Tech Stack

- **HTML5**, **CSS3** (`ultimate-beast.css`, `cyber-tools.css`, `notifications.css`)
- **Vanilla JS** (`ultimate-beast.js`, `cyber-tools.js`, `notification-manager.js`, `site.js`)
- **Font Awesome**, **Google Fonts** (Orbitron, Rajdhani, Space Grotesk)
- **Service Worker** + **PWA manifest**
